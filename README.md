## 📖 এই রিপো তে কি আছে (Ki ache ei repo-te)

`raaj33b/ultapalta` ekta **Gen-Z vibe, jhakanaka UI design** niye banano landing page project — React + Vite + TailwindCSS diye banano, pura **Tarantino-style grindhouse cinematic DOP mood** e. Color palette-e priority dewa hoyeche **moldavite olive-green**, tarpor **wine red**, **royal magenta**, ar **deep purple** — maardanga, vibrant, local-mon-er vibe dhore rakhar jonno.

> ⚠️ Ei project ta ekta **creative/demo showcase** — kono ain-birodhi reverse-engineering tool na। Just design + storytelling exercise, Bangla/Banglish e.

### ✨ Highlights

- 🎬 **Tarantino-DOP inspired cinematic design** — film grain, vignette, flicker, grindhouse color grade
- 🫒 **Moldavite olive-green first** color system, wine red / royal magenta / deep purple accent
- 🗣️ **Banglish copy** — matha-mota formal Bangla na, ekdom rastar bhasha-y lekha
- 🔤 **Bangla display font** (Baloo Da 2) for headings, Hind Siliguri for body
- ⚡ Built with **React 19 + Vite 7 + TailwindCSS 4**
- 📱 Fully responsive, accessible, lightweight single-file build
- 📦 Pura source code `.zip` kore download kora jay website theke

## 🚀 শুরু করো (Getting Started)

### Requirements

- Node.js `>=18`
- npm

### Installation

```bash
git clone https://github.com/raaj33b/ultapalta.git
cd ultapalta
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

Build output `dist/` e thakbe — single-file optimized HTML, deploy kora jabe jekono static host e (GitHub Pages, Vercel, Netlify).
