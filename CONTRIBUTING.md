# 🤝 Contributing to উল্টাপাল্টা (ultapalta)

Prothome dhonnobad je tui contribute korte chaas! Ei doc e shob rules shimple kore deya ache.

## 🧭 Shuru korar age

- Repo fork koro
- `npm install` chalao
- `npm run dev` diye local e dekho shob thik ache kina

## 🐛 Bug Report

- [Issues](https://github.com/raaj33b/ultapalta/issues) e giye notun issue khulo
- Ki hoise, expected ki chilo, screenshot thakle attach koro
- Browser/OS info dile aro valo hoy

## ✨ Feature Request

- Prothome check koro already kew eita request korse kina
- Clear title o description dao, "ken lagbe" ta explain koro

## 🔀 Pull Request Flow

1. Notun branch banao: `git checkout -b feature/tor-feature-naam`
2. Code likho — existing style/convention follow koro (TypeScript + Tailwind)
3. `npm run build` chaliye confirm koro build pass korche
4. Commit message clear rakho: `feat: ...`, `fix: ...`, `docs: ...`
5. Push koro ar PR khulo main branch er dike
6. Review-er jonno wait koro, feedback thakle address koro

## 🎨 Design Guidelines

- Color palette follow koro: Olive-green (priority), wine red, royal magenta, deep purple
- Bangla heading-e `font-bangla` (Baloo Da 2), body text-e `font-bangla-body` (Hind Siliguri) use koro
- Gen-Z / Banglish tone bojay rekho — too formal Bangla lekha theke dure thako

## 📜 License Reminder

Contribute korar mane, tui ei codebase-er license (`LICENSE` file dekho) mene nicho, ebong tor contribution project-er shathe merge hole eita ultapalta-r shorbo shotto-r under thakbe, unless alada vabe negotiate kora hoy.

Dhonnobad abar! Star dite bhulis na ⭐
